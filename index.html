03 / Flagship engineering project

Human-inspired robotic arm
with hybrid control.

FUSION 360ARDUINO UNOTINKERCADMAYAPYTHONYOLOv8 / OPENCV

A single robotic-arm project developed through multiple control approaches: a flex-sensor glove for gesture-based operation, and a camera-based object-detection workflow for automated pick-and-place experiments.

Mechanical concept — articulated arm and human-inspired grasping end-effector
CAD assembly and component integration
Simulation and object-picking motion study
01 / MECHANICAL

Manipulator architecture

Designed the base, shoulder, elbow, wrist and hand-like end-effector in Fusion 360, with the parts arranged as an articulated assembly.

02 / GESTURE INPUT

Flex-sensor glove

Finger bending is used as the human input signal, mapped to servo-driven finger movement for real-time gesture mimicry.

03 / COMPUTER VISION

YOLOv8 + OpenCV

Camera frames are processed for object detection; detection output is used in the robotic-arm control workflow for object approach and grasping.

04 / EMBEDDED

Arduino-based control

Arduino Uno coordinates servo actuation and base rotation hardware. Python scripts connect the vision pipeline with the controller.

05 / ELECTRONICS

Motor driver & power

The circuit integrates servo control with an L293D motor-driver stage for the DC base-rotation motor, with external motor power considered in the wiring layout.

06 / VALIDATION

Simulation & iteration

Autodesk Maya was used to study joint movement, range of motion, coordination and potential interference before physical testing.
