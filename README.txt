HARSH VARDHAN — ENGINEERING PORTFOLIO

HOW TO USE
1. Keep index.html and the assets folder together.
2. Open index.html locally, or upload all files and folders to the root of your GitHub repository.
3. Enable GitHub Pages from Settings > Pages if publishing with GitHub Pages.

IMAGES
Click any project image to open it in a large full-screen viewer. Close with the X, click outside the image, or press Escape.

The Three.js 3D canvas has been removed. The hero now uses the supplied robotic-arm CAD render.
Google Fonts are loaded online; the portfolio images are local files in assets/.
